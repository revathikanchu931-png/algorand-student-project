# Algorand Student Project

## Project Title
Simple Blockchain Application using Algorand

## Objective
This project is created as part of the Algorand course assignment. 
The goal is to learn how blockchain applications work using the Algorand platform.

## Project Description
This project demonstrates a simple decentralized application built on Algorand. 
It explores basic blockchain concepts like transactions and smart contracts.

## Features
- Learn Algorand blockchain basics
- Create sample blockchain transactions
- Understand decentralized applications

## Technologies Used
- Algorand
- Python
- GitHub
